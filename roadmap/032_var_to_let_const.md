# 032: var → let/const 移行

## 規模: M (中)

## 概要
全JSファイルの`var`宣言を`let`または`const`に移行し、
スコープの明確化とバグ防止を図る。

## 該当箇所
- `js/`配下の全ファイル（149ファイル）

## 現状の問題
- `var`は関数スコープのため、ブロック内で宣言してもブロック外からアクセスできてしまう
- 巻き上げ（hoisting）による意図しない動作の可能性
- 再代入可能な変数と不変な変数の区別がつかない
- モダンなJavaScriptの慣例と乖離している

## 修正内容
### 変換ルール
- 再代入されない変数: `var` → `const`
- 再代入される変数: `var` → `let`
- for文のカウンタ: `var i` → `let i`

### 注意事項
- グローバルスコープの`var`は`window`プロパティとして暗黙的に公開される
- `let`/`const`に変更するとグローバルに公開されなくなる
- 他ファイルから参照されるグローバル変数は`window.xxx = `の形式にするか、移行時点では`var`のまま残す

### 段階的移行
1. 関数内ローカル変数の`var`を一括変換（影響が局所的で安全）
2. ファイル内でのみ使われるトップレベル`var`を変換
3. 複数ファイルから参照されるグローバル`var`は最後に対応（ES Modules化と連携）

### 機械的な変換の可否
- ローカル変数の変換はツール（ESLintの`no-var`ルール + `--fix`）で自動化可能
- グローバル変数は手動での確認が必要

## 制約事項
- `file://`プロトコルでの動作が必須
- `let`/`const`への変換自体は`file://`動作に影響しない

## 影響範囲
- `js/`配下の全ファイル
- グローバル変数の参照方法（Phase 3のみ）
