# 漫画のページを作る指針

LLMに「1ページをどう割るか」を判断させるための基準。
**この文書が正で、プロンプトはここから作る。**

抽象的な言い回しは書かない。読んで、そのまま手が動くものだけを書く。

---

## 1. 決める順番

上から順に決める。飛ばさない。

1. **このページで読者に伝えることを列挙する**（箇条書き。1つ1文）
2. **場所が前のページから変わったかを確認する**
3. **列挙したものをコマに1つずつ割り当てる**
4. **各コマの距離を決める**
5. **各コマのアングルを決める**
6. **タグに落とす**

---

## 2. 伝えることを列挙する

ページのあらすじを、読者が受け取る情報の単位に割る。

例：「屋上。彼女が黙っている。彼が問い詰める。彼女は手首を掴まれる」

```
① 場所が屋上に変わった
② 彼が彼女に詰め寄っている
③ 彼女が答えられずにいる
④ 2人は離れて立っている
⑤ 彼が彼女の手首を掴んだ
```

### 数がコマ数と合わないとき

- **多い** → 重要でないものを落とす。次のページへ回さない（次のページには次の情報がある）
- **少ない** → 増やさない。1つの情報を複数コマに分けて見せる
  （例：⑤を「手が伸びる」「掴まれる」の2コマに割る）

**1コマに2つ入れない。** 入れると読者は両方読み落とす。

---

## 3. 場所が変わったかを確認する

前のページと場所が違うなら、**そのページの最初のコマは場所を見せる**。

理由：読者は前のページの場所を頭に持ったままページをめくる。
場所を見せずに人物から始めると、読者は前の場所で会話が続いていると誤解する。

同じ場所が続くなら、場所を見せ直す必要はない。

---

## 4. 距離を決める

**読者に何を伝えたいかで距離が決まる。** 逆はない。

| 伝えたいこと | 距離 | フレームに入るもの |
|---|---|---|
| どこにいるか | 遠景 | 建物・地形・空。人はいないか、点のように小さい |
| 誰が、どこに、どう立っているか | 全身 | 頭から靴まで＋立っている床 |
| 誰が何をしているか | 膝上 | 腰から上＋手 |
| 何を話しているか | 胸から上 | 顔・肩・手ぶり |
| 何を感じているか | 顔 | 目と口。肩から下は入らない |
| 何を持っているか、何が起きたか | 寄り | 手・物・目だけ。周りは入らない |

### 距離を変えるタイミング

**伝えることが変わったときに変える。** コマごとに機械的に変えない。

- ②③④⑤がすべて「会話」なら、全部胸から上でよい
- ②が会話、③が感情なら、②胸から上 → ③顔

**同じ距離が3コマ以上続いたら、そこで本当に同じことを伝えているか確認する。**
違うことを伝えているのに距離が同じなら、読者はその違いに気づかない。

### 人物が写らないコマ

人物なしのコマを入れるのは、次の3つのどれかを伝えるときだけ。

| 伝えたいこと | 何を描くか |
|---|---|
| 場所が変わった | その場所 |
| 時間が経った | 空・時計・窓の外 |
| 直前のコマの余韻 | 直前のコマにあった物（落ちたペン、握った手など） |

**このどれでもないなら入れない。** 「間が必要だから」で入れると、意味のない空きコマになる。

---

## 5. アングルを決める

既定は**目線の高さ**。変えるのは理由があるときだけ。

| アングル | 効果 | 使うとき |
|---|---|---|
| 目線の高さ | 中立 | 特に理由がないとき |
| あおり（下から） | 対象が大きく、強く見える | 威圧する側／見上げている人物の主観 |
| 俯瞰（上から） | 対象が小さく、状況が分かる | 場所の説明／孤立・無力を見せる |
| 傾き | 不安定に見える | 動揺・衝撃・アクション |

**傾きは1ページに1回まで。** 多用すると全部が平坦になる。

---

## 6. コマの大きさと形を使う

コマの大きさと形は既に決まっている（ユーザーが割ったもの）。
**それに合った内容を割り当てる。**

| コマの状態 | 割り当てるもの |
|---|---|
| 大きい | 遠景か、そのページで一番重要なコマ |
| 小さい | 顔か、寄りのコマ |
| 横長 | 遠景・並んだ人物 |
| 縦長 | 立っている人物の全身 |
| 断ち切り（紙の端に接する） | 遠景か、そのページで一番重要なコマ |
| ページ最後のコマ | 次のページを読ませるコマ |

**小さいコマに遠景を入れない。** 縮小されて何も見えなくなる。

**断ち切りは、枠から絵がはみ出すことで人物を強調し、スピード感と迫力を出す。**
枠に収まったコマの中に断ち切りが1つあると、そこが強く見える。
全部を断ち切りにすると、どれも強く見えない。

**1ページのコマ数は6つ程度まで。** それ以上は1コマあたりが小さくなり、
どのコマにも何も描けなくなる（コマ数はユーザーが割るのでLLMは変えられないが、
コマが多いページでは1コマあたりの情報を減らす）。

**見開き（2ページ1枚の絵）は現状このアプリでは扱えない。** ページは1枚ずつ管理される。

---

## 7. ページの最後のコマ

次のページで何が起きるかを踏まえて、次のどれかにする。

- **動作の途中で切る**（手が伸びた、振り上げた）
- **表情で切る**（驚いた顔、無表情）
- **答えを出さずに切る**（問いかけたところ）

**説明で終わらせない。** 「彼らは屋上にいた」で終わると、めくる理由がない。

---

## 8. 背景を描くか描かないか

| コマ | 背景 |
|---|---|
| 遠景・全身・膝上 | 描く。場所が分かるものを2つ以上 |
| 胸から上 | 描く。ただし簡単でよい |
| 顔・寄り | 落としてよい |
| 一番重要なコマ | 落として効果線に置き換えてよい |

**そのページでまだ場所を見せていないなら、落とさない。**
読者が場所を把握する前に背景を消すと、どこの話か分からなくなる。

**同じ場所のコマは、同じ背景の要素を描く。** 1コマ目にフェンスがあって
3コマ目に無いと、読者は別の場所だと思う。

---

## 9. 何が読者を動かすか

8章までは「壊れないための決まり」。ここは「読ませるための作り」。
決まりを全部守っても、これが無ければ読まれない。

### 話の骨格 — 起承転結は型ではなく4つの仕事

順番に並べる型として使うと4分割するだけになる。**それぞれが何の仕事をしているか**が本体。

| | 仕事 | 無いとどうなる |
|---|---|---|
| **起** | 誰の話かを見せ、その人物にとっての「普通」を壊す出来事を置く | 誰を見ればいいか分からないまま進む |
| **承** | 壊れた状態で人物が動く。何が邪魔しているのかが具体的になる | 転が唐突に見える |
| **転** | 読者と人物の予想が外れる。**ここが一番見せたい場面** | 平坦。読み終えて何も残らない |
| **結** | 転の結果、何が変わったか | 投げっぱなしに見える |

**転が無い話は、何ページ描いても漫画にならない。** 順番を守ることより、
この4つの仕事が全部あることが重要。

### 骨格の崩し方

型どおりが常に良いわけではない。よく使われる崩し。

| 崩し | やり方 | 効くとき |
|---|---|---|
| **転から始める** | 一番強い場面を1ページ目に置き、そこへ時間を戻す | 起が地味で掴みが弱い話 |
| **起を省く** | 説明せず、既に事が起きている途中から入る | ページ数が少ない |
| **結を置かない** | 転の直後で切る | 余韻を残したい／続きがある |
| **承を2段にする** | 障害を乗り越えたらもっと大きい障害が出る | ページ数が多い |
| **転を2回** | 一度解決したと見せて覆す | 読者を出し抜きたい |

### 1ページ目は掴み

**1ページ目で読者が離れたら、残りは読まれない。** ここだけは外せない。

- **1ページ目に「絵として強いコマ」を必ず1つ置く。** 大ゴマか断ち切り
- 説明から始めない。設定・世界観・人物紹介は後
- 「これは何が起きているんだ」と思わせる状態で開く

読切では、1ページ目か最初の見開きに一番強い絵を置くのが普通。
**話の順番より掴みを優先してよい**（→ 骨格の崩し方「転から始める」）。

### 溜めと解放

**見せ場は単体では効かない。前に溜めがあって初めて効く。**

| | 使うもの |
|---|---|
| 溜め | 小さいコマ、静かな絵、人のいないコマ、沈黙 |
| 解放 | 大ゴマ、断ち切り、効果線、寄り |

**溜めなしに大ゴマを並べると、どれも見せ場に見えない。**
1ページの中でも、ページとページの間でも同じ。

### 落差

読者が反応するのは、**状態が変わった瞬間**。変化そのものが情報になる。

| 落差 | 例 |
|---|---|
| 静 → 動 | 黙っていた人物が急に動く |
| 遠 → 近 | 引きの絵の次に顔のアップ |
| 賑やか → 無人 | 人が大勢いる場面の次に誰もいないコマ |
| 喋る → 黙る | 喋り続けた後の沈黙 |
| 明 → 暗 | 昼の場面の次に夜 |

**同じ調子が続くと、何が起きても読者は反応しない。**

### 感情は説明せず、行動で見せる

| 悪い | 良い |
|---|---|
| 悲しい表情 | 何も言わずに立ち上がって出ていく |
| 怒っている | 持っていたものを置く手が止まる |
| 好きだった | 話しかけようとして、言葉が出ずに背を向けた |

**「〜な気持ち」と書くと、絵にできない。** 何をしたかを書く。

## 10. 視線誘導

日本の漫画は**右上から左下**へ読む。コマの中も、セリフの順も同じ。
読者の視線はZを鏡映しにした形で動く。

### アプリ側が持っているもの・LLMが決めるもの

| | 誰が決めるか |
|---|---|
| コマの位置・大きさ・間隔 | ユーザーがキャンバス上で割る |
| 吹き出しの位置 | ユーザーが置く |
| **コマの中の人物の向き・視線** | **LLMがタグで決める** |

**読者の視線を一番強く引くのは吹き出し。** 次が人物の視線。
吹き出しはアプリ側なので、LLMが効かせられるのは**人物の視線**だけ。

### 視線をつなぐ

**人物の視線の先に、次に読ませたいものを置く。**
キャラが見ている方向へ読者の視線も動く。

| やりたいこと | 書くタグ |
|---|---|
| 2人の会話を往復させる | `looking at another`（互いを見ている） |
| 次のコマへ流す | `looking to the side` / `profile`（横を向く） |
| 背中で語る・去る | `from behind` |
| 振り返る | `looking back` |

**左右の向きはタグで指定できない。** `facing left` `facing right` はDanbooruに無い。
「横を向いている」までしか指定できないので、左右はコマの配置で読者が補う。

### カメラ目線は使いどころが1つだけある

既定ではカメラ目線を避ける（→ 16章）。漫画のコマで読者と目が合うと、
**そこで視線が止まる**。流れが切れる。

**だからこそ、止めたいコマでだけ使う。**

- ページの最後のコマ（次をめくらせる前に一度止める）
- 見せ場（読者に突きつける）
- 読者に語りかけるモノローグ

それ以外のコマでは `looking at another` などで外す。

## 11. セリフとコマの関係

**読者はまずセリフを読む。** 絵より先に文字へ視線が行く。

### セリフの置き場所を絵で潰さない

**吹き出しはアプリ側で後から絵の上に乗せる。** 人物を画面いっぱいに描くと、
乗せる場所が無くなり、顔の上に吹き出しが来る。

「余白を残せ」ではタグにならない。**実際に効くのは次の2つだけ。**

#### ① 距離を1段引く

**喋っているコマを `closeup` にしない。** 人物が小さくなるほど余白が増える。

| そのコマのセリフ | 距離 |
|---|---|
| 吹き出し3つ以上 | 膝上（`medium`）か全身（`full`）。人物が小さいほど空く |
| 吹き出し1〜2つ | 胸から上（`medium`） |
| 一言、または無し | 顔（`closeup`）まで寄ってよい |

#### ② 頭より上にあるものを名指しする

フレームの端にあるものを名指しするとフレームが広がる（→ 16章）。
**これは余白を作るのにも使える。頭上にあるものを書けば、頭上が空く。**

| 場所 | 頭上に書くもの |
|---|---|
| 屋外 | `sky` / `clouds` |
| 室内 | `ceiling` / `ceiling light` |
| 廊下・部屋 | `wall` / `window` |

#### やってはいけない

「余白を空ける」「上に空間を作る」はタグにならない。
`empty space` `negative space` のような指示は効かない。
**空くのは、そこに何かを名指ししたときだけ。**

### セリフの量とコマの絵は反比例

- セリフが多い → 絵は単純に（背景を落とす、動きを止める）
- 絵が複雑（遠景・アクション・見せ場） → セリフは短く、または無し

**両方を詰めると、どちらも読まれない。**

### セリフの書き方

- 1つの吹き出しは短く。**主語 → 目的 → 行動**の順
- モノローグは情景描写ではなく**心理の変化**を書く
- 説明台詞を避ける。「ここは屋上だ」は絵が言っている

### 擬音

擬音（ドカッ、シーン）は**アプリのテキストで入れる。画像に文字を描かせない。**
画像生成に文字を描かせると読めない字が出る（→ 16章「出してはいけないタグ」）。

## 12. キャラクターを立てる

### 話の側

| 要素 | 中身 |
|---|---|
| **欠点** | 完璧な主人公は魅力が無い。何かが欠けている |
| **欲求** | 何が欲しいか。それが行動の理由になる |
| **ギャップ** | 見た目と中身、または普段と非常時で違う |
| **初登場で何をするか** | 最初の1コマの行動でキャラが決まる。説明ではなく行動 |

**設定を細かく作ることが目的ではない。** 1つか2つを強く出すほうが印象に残る。

### 絵の側 — シルエットで見分けがつくか

**AI生成では、似た見た目のキャラを描き分けられない。**
顔を揃える手段がタグの一致しかないので（→ `prompt-composition.md` 8.5章）、
**同じような髪型・髪色・服の人物が2人いると混ざる。**

キャラ表を作るとき、互いに以下を変える。

| 変えるもの | 例 |
|---|---|
| 髪の長さ | 短髪 / 肩まで / 長髪 |
| 髪の色 | 黒 / 明るい色 / 白 |
| 服の系統 | 制服 / 私服 / 上着あり |
| 目立つ1点 | 眼鏡 / 帽子 / 髪飾り / 傷 |

**「目立つ1点」を各キャラに1つずつ与える。** これが一番効く。
全コマにそのタグが入るので、そのコマだけ見ても誰か分かる。

---

## 13. 表情は振り切れる

**素の喜怒哀楽タグ（`angry` `sad` `smile` `surprised`）を書くと、大げさな顔になる。**

学習データは1枚絵のイラストで、1枚だけで感情を伝えるため表情が強い。
漫画のコマは、セリフ・視線・仕草・前後のコマで感情を伝えるので、**表情自体は抑えめでよい**。

`angry` と書くとV字眉・大口の怒鳴り顔になる。
実際の漫画の「怒っている」はほとんどが、ムッとした口元・真顔・目をそらす・拳を握る、の組み合わせ。

### 素のタグがどれだけ強いか

| タグ | Danbooru件数 | 出るもの |
|---|---:|---|
| `smile` | 4,076,048 | 全開の笑顔 |
| `blush` | 4,014,266 | 真っ赤 |
| `open mouth` | 3,429,508 | 大きく開いた口。**どの感情タグと組んでも叫び顔になる** |
| `closed mouth` | 1,908,889 | 閉じた口 |
| `v-shaped eyebrows` | 260,067 | 漫画的な怒り眉。`angry` に付いてくる |

**指定しないと口は開く。抑えた表情には `closed mouth` を明示する。**

### 怒り — 段階で選ぶ

| 強さ | タグ | 件数 |
|---|---|---:|
| **真顔で押す（一番よく使う）** | `expressionless` + `closed mouth` | 176,796 |
| 硬い顔 | `serious` + `closed mouth` | 39,081 |
| ムッとする | `frown` + `closed mouth` | 151,309 |
| 冷たく見る・呆れる | `half-closed eyes` + `frown` | 140,901 |
| 目をそらす | `averting eyes` + `frown` | 20,171 |
| 睨む | `glaring` | 12,185 |
| 手で見せる | `clenched hand` + `frown` | 85,820 |
| 食いしばる | `clenched teeth` | 103,571 |
| **爆発（1ページに1回まで）** | `angry` + `v-shaped eyebrows` + `open mouth` | 60,690 |

### 悲しみ

| 強さ | タグ |
|---|---|
| 沈む | `looking down` + `closed mouth` |
| こらえる | `closed eyes` + `frown` |
| 泣きそう | `tearing up` / `wavy mouth` |
| 涙が出る | `tears` |
| **号泣（1回まで）** | `crying` + `open mouth` |

### 喜び

| 強さ | タグ |
|---|---|
| かすかに | `light smile` + `closed mouth` |
| 微笑む | `smile` + `closed mouth` |
| 笑う | `smile` + `open mouth` |
| **大笑い（1回まで）** | `laughing` / `grin` |

### 驚き

| 強さ | タグ |
|---|---|
| 息を呑む | `parted lips` / `wide-eyed` |
| 驚く | `surprised` + `closed mouth` |
| **仰天（1回まで）** | `surprised` + `open mouth` |

### 表情より仕草で見せる

漫画では表情そのものより、**仕草と視線**が感情を運ぶ。

| 感情 | 仕草のタグ |
|---|---|
| 怒り | `clenched hand`（拳）/ `averting eyes`（目をそらす） |
| 動揺 | `sweat` / `sweatdrop` / `trembling` |
| 落胆 | `looking down` / `shaded face`（顔に影） |
| ためらい | `from behind`（背を向ける） |

`shaded face`（80,075）は漫画的な「顔に影を落とす」表現そのもの。
沈んだ感情に効く。

### 存在しないタグを書かない

**書きがちだが Danbooru に無い（＝効かない）タグ。**

| 書きがち | 件数 | 代わりに使う |
|---|---:|---|
| `biting lip` | 0 | `frown` / `clenched teeth` |
| `hand over mouth` | 0 | `covering face`（10,253） |
| `teary eyes` | 0 | `tearing up`（71,045）/ `tears` |
| `downcast eyes` | 202 | `looking down`（136,399） |

## 14. ストーリーをページ数に合わせる

ユーザーが入力するストーリーは、ページ数に対して短すぎるか長すぎる。
**どちらの方向にも合わせる。**

- **短い**（「幼馴染に告白する話」の1行）→ そのまま配ると各ページが空になる。足す
- **長い**（8ページに30ページ分）→ そのまま配ると1ページに詰め込みすぎる。削る

### 変えていいもの・いけないもの

| | 扱い |
|---|---|
| 入力が決めていること（誰が出るか／何が起きるか／どう終わるか） | **変えない** |
| それ以外（経緯、場面の数、細部、脇役） | 足す・まとめる・削る |

### 短いときに足すもの

| 足すもの | 決め方 |
|---|---|
| 登場人物 | 話に必要な最小限。名前と、互いの関係 |
| 場所 | 話が実際に動く場所だけ |
| 動機 | その人物がなぜそうするのか |
| 障害 | なぜすぐに達成できないのか |
| 一番見せたい場面 | 読者がこの話を読む理由になる場面 |
| 結末 | 障害がどうなったか（入力に無ければ） |

### 長いときに削るもの

**削る順番。上から削る。**

1. 説明だけの場面（移動、経過、回想）
2. 脇役とその場面
3. 同じことを2回見せている場面（片方を残す）
4. 一番見せたい場面から遠い場面

**一番見せたい場面と結末は最後まで残す。** ここを削ると話が成立しない。

### 人物と場所は増やしすぎない

**AI生成では、登場人物が増えるほど描き分けが崩れる。**
同一人物を保つ手段が今はタグの一致だけで、顔は揃わない
（→ `prompt-composition.md` 8.5章）。場所も同じで、同じ背景を描き続けるのは難しい。

**人物は3〜4人まで、場所は2〜3箇所までに収める。**
物語の都合ではなく、絵が保たない側の都合。長い入力を削るときも、
まずここに収まるまで人物と場所を減らす。

### 量をページ数に合わせる

**1つの場面は1〜3ページに収まる。** ページ数から場面の数を見当づける。

| ページ数 | 場面の数 |
|---|---|
| 8ページ | 3〜5場面 |
| 18ページ | 6〜10場面 |
| 30ページ | 10〜15場面 |

場面が多すぎると1場面が1ページ未満になり、何も描けない。
少なすぎると1場面を4ページ以上に引き伸ばすことになり、間延びする。

### 書き方

**場面ごとに段落を分ける。** 1段落に「どこで」「誰がいるか」「何が起きるか」。

**説明ではなく、起きることを書く。**

- 悪い: 彼は彼女が好きだった
- 良い: 彼は彼女に話しかけようとして、言葉が出ずに背を向けた

ここではページ単位・コマ単位に割らない。それは次の段。

## 15. ストーリーをページに配分する

### 手順

1. **一番見せたい場面を決める**（クライマックス）
2. **それが何ページ目に来るかを決める**（全体の2/3〜3/4あたり）
3. **そこへ向かう過程を前に配る**
4. **その後を残りに配る**

### ページ数の配り方

**ページ数＝その場面の重み。**

| 場面の役割 | ページ数の目安 |
|---|---|
| 説明だけの場面（移動、経過） | 1ページ以下。または省く |
| 話が動く場面 | 1〜2ページ |
| 一番見せたい場面 | 2〜3ページ |

**説明にページを使わない。** 読者は説明を読みたいのではない。

### 1ページ目

**1ページ目で読者が「続きを読む理由」を得られるようにする。**

- 何かが起きている途中から始める
- または、何かが隠されている状態で始める

**設定の説明から始めない。** 読者はまだその設定に興味がない。

### 最後のページ

1ページ目で作った「気になること」に答える。

## 16. AI画像生成に落とすときの注意

ここからは漫画の話ではなく、画像生成モデルの都合。

### 距離はタグで指定できない

`full body` `wide shot` `upper body` `close-up` と書いても、そうならない。
これらは出来上がった絵に後から付けられたラベルであって、命令ではない。

**距離を決めるのは、フレームに入る物を名指ししたかどうか。**

| 欲しい距離 | 書くもの | 書いてはいけないもの |
|---|---|---|
| 全身 | 靴、靴下、脚、立っている床 | — |
| 膝上 | 腰から上の服、手 | 靴、床 |
| 胸から上 | 上着、髪、顔 | スカート、靴、床 |
| 顔 | 目、口、髪、表情 | 服、肩から下、床 |
| 遠景 | 建物、フェンス、空など、フレームに収まりきらない大きさの物 | 人物のパーツ |

**フレームの外にある物を書くと、それを収めようとして絵が引く。**
顔のコマに「靴」を書くと全身になる。

`wide shot` などを添えるのは構わないが、**書く物と矛盾しない範囲でしか効かない。**

### 何も指定しないとこうなる

学習データはイラスト単体の集まりで、漫画のページではない。だから既定は
**「1人・胸から膝上・正面・カメラ目線」**に寄る。

| タグ | Danbooruの件数 |
|---|---:|
| `looking_at_viewer` | 4,793,726 |
| `upper_body` | 1,165,014 |
| `cowboy_shot` | 831,263 |
| `wide_shot` | 23,183 |
| `very_wide_shot` | 2,190 |

`looking_at_viewer` が過半数を占める。漫画のコマで読者と目が合うのは
意図した演出のときだけなので、**カメラ目線でないことを明示する**必要がある
（`looking at another` `looking away` など）。

### 人数

コマごとに、そのコマに写っている人数を書く（`1girl` / `1boy, 1girl` / `2girls`）。
前のコマから引き継がない。1人しか写っていないときだけ `solo`。

### タグの数

**そのコマで読者が見るものを書いて、そこで止める。**

- 少なすぎる → モデルが勝手に埋める
- 多すぎる → 1つ1つが弱くなり、距離を決めるタグまで効かなくなる

遠景は多くなる（8〜12個）。顔だけは少なくなる（5〜8個）。

### 見切れ

腕や脚が枠で切れた絵は後から直せないので、常にネガティブに入れる。
意図して切りたいときは、生成後に画像をコマ枠へ寄せる（アプリ側の操作）。

### 出してはいけないタグ

`comic` `panel` `border` `speech bubble` `text` `4koma`
枠と吹き出しはアプリが描く。

## 17. 確認

書き終わったら、次を確認する。

- [ ] 1コマに2つの情報を入れていないか
- [ ] 場所が変わったページで、最初に場所を見せているか
- [ ] 同じ距離が3コマ以上続いていて、しかも違うことを伝えていないか
- [ ] 人物なしのコマは、場所・時間経過・余韻のどれかを担っているか
- [ ] 小さいコマに遠景を入れていないか
- [ ] 顔のコマに靴や床を書いていないか
- [ ] 場所を見せる前に背景を落としていないか
- [ ] 同じ場所のコマで、同じ背景の要素を書いているか
- [ ] 最後のコマが説明で終わっていないか
- [ ] キャラでも場所でもないタグが、大半のコマに入っていないか
- [ ] 全コマがカメラ目線になっていないか（止めたいコマだけ）
- [ ] セリフが多いコマで、人物に寄りすぎて吹き出しの置き場所が無くなっていないか
- [ ] 登場人物どうしが、髪型・髪色・服・目立つ1点のどれかで見分けられるか
- [ ] 断ち切りが全コマになっていないか
- [ ] 素の喜怒哀楽タグ（angry / sad / smile / surprised）を安易に使っていないか
- [ ] 抑えた表情のコマに closed mouth を入れたか
- [ ] 振り切った表情がページに2つ以上出ていないか
- [ ] 喋るコマを closeup にして、吹き出しの置き場所を潰していないか
