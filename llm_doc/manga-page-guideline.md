# 漫画のページを作る指針

LLMに「1ページをどう割るか」を判断させるための基準。
**この文書が正で、プロンプトはここから作る。**

抽象的な言い回しは書かない。読んで、そのまま手が動くものだけを書く。

---

## 1. 決める順番

上から順に決める。飛ばさない。

1. **このページで読者に伝えることを列挙する**（箇条書き。1つ1文）
2. **場所が前のページから変わったかを確認する**
3. **列挙したものをコマに1つずつ割り当てる**
4. **各コマの距離を決める**
5. **各コマのアングルを決める**
6. **タグに落とす**

---

## 2. 伝えることを列挙する

ページのあらすじを、読者が受け取る情報の単位に割る。

例：「屋上。彼女が黙っている。彼が問い詰める。彼女は手首を掴まれる」

```
① 場所が屋上に変わった
② 彼が彼女に詰め寄っている
③ 彼女が答えられずにいる
④ 2人は離れて立っている
⑤ 彼が彼女の手首を掴んだ
```

### 数がコマ数と合わないとき

- **多い** → 重要でないものを落とす。次のページへ回さない（次のページには次の情報がある）
- **少ない** → 増やさない。1つの情報を複数コマに分けて見せる
  （例：⑤を「手が伸びる」「掴まれる」の2コマに割る）

**1コマに2つ入れない。** 入れると読者は両方読み落とす。

---

## 3. 場所が変わったかを確認する

前のページと場所が違うなら、**そのページの最初のコマは場所を見せる**。

理由：読者は前のページの場所を頭に持ったままページをめくる。
場所を見せずに人物から始めると、読者は前の場所で会話が続いていると誤解する。

同じ場所が続くなら、場所を見せ直す必要はない。

---

## 4. 距離を決める

**読者に何を伝えたいかで距離が決まる。** 逆はない。

| 伝えたいこと | 距離 | フレームに入るもの |
|---|---|---|
| どこにいるか | 遠景 | 建物・地形・空。人はいないか、点のように小さい |
| 誰が、どこに、どう立っているか | 全身 | 頭から靴まで＋立っている床 |
| 誰が何をしているか | 膝上 | 腰から上＋手 |
| 何を話しているか | 胸から上 | 顔・肩・手ぶり |
| 何を感じているか | 顔 | 目と口。肩から下は入らない |
| 何を持っているか、何が起きたか | 寄り | 手・物・目だけ。周りは入らない |

### 距離を変えるタイミング

**伝えることが変わったときに変える。** コマごとに機械的に変えない。

- ②③④⑤がすべて「会話」なら、全部胸から上でよい
- ②が会話、③が感情なら、②胸から上 → ③顔

**同じ距離が3コマ以上続いたら、そこで本当に同じことを伝えているか確認する。**
違うことを伝えているのに距離が同じなら、読者はその違いに気づかない。

### 人物が写らないコマ

人物なしのコマを入れるのは、次の3つのどれかを伝えるときだけ。

| 伝えたいこと | 何を描くか |
|---|---|
| 場所が変わった | その場所 |
| 時間が経った | 空・時計・窓の外 |
| 直前のコマの余韻 | 直前のコマにあった物（落ちたペン、握った手など） |

**このどれでもないなら入れない。** 「間が必要だから」で入れると、意味のない空きコマになる。

---

## 5. アングルを決める

既定は**目線の高さ**。変えるのは理由があるときだけ。

| アングル | 効果 | 使うとき |
|---|---|---|
| 目線の高さ | 中立 | 特に理由がないとき |
| あおり（下から） | 対象が大きく、強く見える | 威圧する側／見上げている人物の主観 |
| 俯瞰（上から） | 対象が小さく、状況が分かる | 場所の説明／孤立・無力を見せる |
| 傾き | 不安定に見える | 動揺・衝撃・アクション |

**傾きは1ページに1回まで。** 多用すると全部が平坦になる。

---

## 6. コマの大きさと形を使う

コマの大きさと形は既に決まっている（ユーザーが割ったもの）。
**それに合った内容を割り当てる。**

| コマの状態 | 割り当てるもの |
|---|---|
| 大きい | 遠景か、そのページで一番重要なコマ |
| 小さい | 顔か、寄りのコマ |
| 横長 | 遠景・並んだ人物 |
| 縦長 | 立っている人物の全身 |
| 断ち切り（紙の端に接する） | 遠景か、そのページで一番重要なコマ |
| ページ最後のコマ | 次のページを読ませるコマ |

**小さいコマに遠景を入れない。** 縮小されて何も見えなくなる。

---

## 7. ページの最後のコマ

次のページで何が起きるかを踏まえて、次のどれかにする。

- **動作の途中で切る**（手が伸びた、振り上げた）
- **表情で切る**（驚いた顔、無表情）
- **答えを出さずに切る**（問いかけたところ）

**説明で終わらせない。** 「彼らは屋上にいた」で終わると、めくる理由がない。

---

## 8. 背景を描くか描かないか

| コマ | 背景 |
|---|---|
| 遠景・全身・膝上 | 描く。場所が分かるものを2つ以上 |
| 胸から上 | 描く。ただし簡単でよい |
| 顔・寄り | 落としてよい |
| 一番重要なコマ | 落として効果線に置き換えてよい |

**そのページでまだ場所を見せていないなら、落とさない。**
読者が場所を把握する前に背景を消すと、どこの話か分からなくなる。

**同じ場所のコマは、同じ背景の要素を描く。** 1コマ目にフェンスがあって
3コマ目に無いと、読者は別の場所だと思う。

---

## 9. ストーリーをページ数に合わせる

ユーザーが入力するストーリーは、ページ数に対して短すぎるか長すぎる。
**どちらの方向にも合わせる。**

- **短い**（「幼馴染に告白する話」の1行）→ そのまま配ると各ページが空になる。足す
- **長い**（8ページに30ページ分）→ そのまま配ると1ページに詰め込みすぎる。削る

### 変えていいもの・いけないもの

| | 扱い |
|---|---|
| 入力が決めていること（誰が出るか／何が起きるか／どう終わるか） | **変えない** |
| それ以外（経緯、場面の数、細部、脇役） | 足す・まとめる・削る |

### 短いときに足すもの

| 足すもの | 決め方 |
|---|---|
| 登場人物 | 話に必要な最小限。名前と、互いの関係 |
| 場所 | 話が実際に動く場所だけ |
| 動機 | その人物がなぜそうするのか |
| 障害 | なぜすぐに達成できないのか |
| 一番見せたい場面 | 読者がこの話を読む理由になる場面 |
| 結末 | 障害がどうなったか（入力に無ければ） |

### 長いときに削るもの

**削る順番。上から削る。**

1. 説明だけの場面（移動、経過、回想）
2. 脇役とその場面
3. 同じことを2回見せている場面（片方を残す）
4. 一番見せたい場面から遠い場面

**一番見せたい場面と結末は最後まで残す。** ここを削ると話が成立しない。

### 人物と場所は増やしすぎない

**AI生成では、登場人物が増えるほど描き分けが崩れる。**
同一人物を保つ手段が今はタグの一致だけで、顔は揃わない
（→ `prompt-composition.md` 8.5章）。場所も同じで、同じ背景を描き続けるのは難しい。

**人物は3〜4人まで、場所は2〜3箇所までに収める。**
物語の都合ではなく、絵が保たない側の都合。長い入力を削るときも、
まずここに収まるまで人物と場所を減らす。

### 量をページ数に合わせる

**1つの場面は1〜3ページに収まる。** ページ数から場面の数を見当づける。

| ページ数 | 場面の数 |
|---|---|
| 8ページ | 3〜5場面 |
| 18ページ | 6〜10場面 |
| 30ページ | 10〜15場面 |

場面が多すぎると1場面が1ページ未満になり、何も描けない。
少なすぎると1場面を4ページ以上に引き伸ばすことになり、間延びする。

### 書き方

**場面ごとに段落を分ける。** 1段落に「どこで」「誰がいるか」「何が起きるか」。

**説明ではなく、起きることを書く。**

- 悪い: 彼は彼女が好きだった
- 良い: 彼は彼女に話しかけようとして、言葉が出ずに背を向けた

ここではページ単位・コマ単位に割らない。それは次の段。

## 10. ストーリーをページに配分する

### 手順

1. **一番見せたい場面を決める**（クライマックス）
2. **それが何ページ目に来るかを決める**（全体の2/3〜3/4あたり）
3. **そこへ向かう過程を前に配る**
4. **その後を残りに配る**

### ページ数の配り方

**ページ数＝その場面の重み。**

| 場面の役割 | ページ数の目安 |
|---|---|
| 説明だけの場面（移動、経過） | 1ページ以下。または省く |
| 話が動く場面 | 1〜2ページ |
| 一番見せたい場面 | 2〜3ページ |

**説明にページを使わない。** 読者は説明を読みたいのではない。

### 1ページ目

**1ページ目で読者が「続きを読む理由」を得られるようにする。**

- 何かが起きている途中から始める
- または、何かが隠されている状態で始める

**設定の説明から始めない。** 読者はまだその設定に興味がない。

### 最後のページ

1ページ目で作った「気になること」に答える。

## 11. AI画像生成に落とすときの注意

ここからは漫画の話ではなく、画像生成モデルの都合。

### 距離はタグで指定できない

`full body` `wide shot` `upper body` `close-up` と書いても、そうならない。
これらは出来上がった絵に後から付けられたラベルであって、命令ではない。

**距離を決めるのは、フレームに入る物を名指ししたかどうか。**

| 欲しい距離 | 書くもの | 書いてはいけないもの |
|---|---|---|
| 全身 | 靴、靴下、脚、立っている床 | — |
| 膝上 | 腰から上の服、手 | 靴、床 |
| 胸から上 | 上着、髪、顔 | スカート、靴、床 |
| 顔 | 目、口、髪、表情 | 服、肩から下、床 |
| 遠景 | 建物、フェンス、空など、フレームに収まりきらない大きさの物 | 人物のパーツ |

**フレームの外にある物を書くと、それを収めようとして絵が引く。**
顔のコマに「靴」を書くと全身になる。

`wide shot` などを添えるのは構わないが、**書く物と矛盾しない範囲でしか効かない。**

### 何も指定しないとこうなる

学習データはイラスト単体の集まりで、漫画のページではない。だから既定は
**「1人・胸から膝上・正面・カメラ目線」**に寄る。

| タグ | Danbooruの件数 |
|---|---:|
| `looking_at_viewer` | 4,793,726 |
| `upper_body` | 1,165,014 |
| `cowboy_shot` | 831,263 |
| `wide_shot` | 23,183 |
| `very_wide_shot` | 2,190 |

`looking_at_viewer` が過半数を占める。漫画のコマで読者と目が合うのは
意図した演出のときだけなので、**カメラ目線でないことを明示する**必要がある
（`looking at another` `looking away` など）。

### 人数

コマごとに、そのコマに写っている人数を書く（`1girl` / `1boy, 1girl` / `2girls`）。
前のコマから引き継がない。1人しか写っていないときだけ `solo`。

### タグの数

**そのコマで読者が見るものを書いて、そこで止める。**

- 少なすぎる → モデルが勝手に埋める
- 多すぎる → 1つ1つが弱くなり、距離を決めるタグまで効かなくなる

遠景は多くなる（8〜12個）。顔だけは少なくなる（5〜8個）。

### 見切れ

腕や脚が枠で切れた絵は後から直せないので、常にネガティブに入れる。
意図して切りたいときは、生成後に画像をコマ枠へ寄せる（アプリ側の操作）。

### 出してはいけないタグ

`comic` `panel` `border` `speech bubble` `text` `4koma`
枠と吹き出しはアプリが描く。

---

## 12. 確認

書き終わったら、次を確認する。

- [ ] 1コマに2つの情報を入れていないか
- [ ] 場所が変わったページで、最初に場所を見せているか
- [ ] 同じ距離が3コマ以上続いていて、しかも違うことを伝えていないか
- [ ] 人物なしのコマは、場所・時間経過・余韻のどれかを担っているか
- [ ] 小さいコマに遠景を入れていないか
- [ ] 顔のコマに靴や床を書いていないか
- [ ] 場所を見せる前に背景を落としていないか
- [ ] 同じ場所のコマで、同じ背景の要素を書いているか
- [ ] 最後のコマが説明で終わっていないか
- [ ] キャラでも場所でもないタグが、大半のコマに入っていないか
