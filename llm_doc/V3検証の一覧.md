# V3検証の一覧

作成 2026-09-30。V3で確かめる必要があるものを、漏れなく1か所に集めた一覧。

## この文書の位置づけ
- 試作で確かめた結果は `llm_doc/V3検証の結果.md`（行ごとの結果とメモは `v3poc/checklist/checklist.html`）。環境の作り方は `llm_doc/V3検証の環境.md`。
- 元にした文書
  - `llm_doc/V3ハーネスの方針と課題.md`：方針1〜20、候補1〜103、課題1〜325。以下「方針n」「候補n」「課題n」。
  - `llm_doc/V3ハーネス設計.md`：以下「設計」。
  - `llm_doc/V3細部の決めごと.md`：以下「細部」。
  - `llm_doc/V3調査/` の4ファイル。課題に移していなかったものは、2026-09-30に課題246〜260として足した。
- 確かめることは5種類。
  - **起きるか**：AIが実際にその問題を起こすか。どのくらいの割合で起こすか。講座から作った課題は、AIが破るかを確かめていない（方針と課題の「読み方」）。
  - **防げるか**：設計の手で、その問題を防げるか。
  - **見つけられるか**：検査・検出器・評価役が、その問題をどのくらい当てるか。
  - **作れるか**：仕組みが作れるか。狙いどおりに動くか。
  - **調べる**：資料で確かめる。
- 漏れの確かめ方：課題1〜325、候補1〜103、方針1〜20の番号は、下の表のどこかに必ず入れた。入っていることは、表から番号を抜き出して機械で確かめた（2026-09-30）。
- 測り方の「毎回成功の率」は、同じ指示をk回出して全部成功した割合（候補55）。「人と突き合わせる」は設計7.3の手順。
