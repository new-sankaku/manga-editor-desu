# V3ハーネスの方針と課題

作成 2026-09-27。V3（サーバー化した漫画作成用のAIハーネス）を作るときの「方針」「方針に足す候補」「解決の必要がある課題」の一覧。各項目に狙い（何を防ぐか）と出どころを付けた。

## 前提
- V3のハーネスはフルスクラッチで作る。既存のjs・llm_doc・PoC・検証記録は根拠にも解決策にも使っていない。
- 出どころは「あなた（ユーザーが挙げた）」「会話（この会話で決めた・出た）」「推測（未確認）」と、実際に読んだWeb資料だけ。
- 調べた資料の全URL・読めたかどうか・数字の表は `llm_doc/V3調査/` の4ファイルにある。
  - `ハーネス設計の調査.md`：Anthropic・OpenAI・Cognition・Google・LangChain・Manus の記事と2026年の論文（69件）
  - `漫画生成AIの研究調査.md`：漫画・コミック生成の論文（47件）
  - `絵の評価の研究調査.md`：AIに絵を評価させる研究（77件）
  - `漫画の描き方講座の調査.md`：小学館・集英社・現役漫画家の講座（81件、うち決まりが書かれていたのは67件）

## 読み方
- 本文はWebFetch（本文を小型モデルが抜き出して返す）で読んだ。数字は抜き出し経由で、原典の表と照合したのは MangaFlow・DreamingComics・DiffSensei の主な表だけ。
- 「要旨のみ」＝本文を読めず要旨だけ読んだ。
- 候補の「強さ」：実測＝数値で比べた／事例＝会社の運用報告／意見＝主張だけ。
- ハーネスの資料はほぼソフトウェア開発の話。**「狙い」欄の漫画への当てはめは推測で、効くかは未検証。**
- 講座から作った課題は、講座に「守らないとこうなる」と書かれていた決まり。**AIが実際に破るかは未確認。** 守らせ方・確かめ方が決まっていないので課題に入れた。

## 用語
| 用語 | 意味 |
|---|---|
| 作業役・評価役 | 作業役はネームや絵を作るAI。評価役はそれを採点するAI |
| 文脈 | 1回の呼び出しでAIに渡す文章と画像の全部。長いほど費用が増え、判断が落ちる |
| キャッシュ | 前回と同じ先頭部分を提供元が覚えておき、安く速く処理する仕組み |
| LLM・VLM | LLMは文章のAI。VLMは画像も読めるAI |
| 1回でも成功・毎回成功 | 同じ依頼をk回回して、1回でも成功すれば成功とする測り方（pass@k）と、k回すべて成功して初めて成功とする測り方（pass^k） |
| 回帰の評価 | 以前できていたことが、変更後も壊れていないかを確かめる評価 |
| トレース | AIが何を読み、何を考え、何を呼んだかの記録 |
| F1・AP | 検出の当たり具合。0〜1で、1に近いほど見逃しも誤検出も少ない |
| 相関 | 2つの採点がどれだけ揃うか。1で完全に一致、0で無関係 |
| ノド | 本の綴じ側 |
| 断ち切り | 絵を紙の端まで描くコマ |
| ベタ・トーン | ベタは黒く塗る部分、トーンは網点の濃淡 |
| 大ゴマ・決めゴマ | 見せ場のための大きいコマ |
| めくり・ヒキ | ヒキはめくる前のページ最後の「続きが気になる」コマ、めくりはめくった直後のコマ |
| Q | 文字の大きさの単位。1Q＝0.25mm |
