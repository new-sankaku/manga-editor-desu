# V3検証の環境

作成 2026-09-30。`llm_doc/V3検証の一覧.md` の項目を小さな試作（PoC）で確かめるための環境の作り方と、試作の動かし方。結果は `llm_doc/V3検証の結果.md`。

## 置き場所
- 試作と成果物：`v3poc/`（リポジトリの中。消さない）
  - `v3poc/common/`：共通の部品。ComfyUIへの依頼（`comfy.py`）、人物と顔の検出（`detect.py`）、目で見る一覧画像（`sheet.py`）
  - `v3poc/pNN_名前/`：試作ごとのフォルダ。`run.py` が生成、`analyze.py` が測定。出力は `out/`（画像・`result.json`・`run.log`）
  - `v3poc/checklist/`：検証の一覧をメモ付きで見るHTML（下の「一覧のHTML」）
  - `v3poc/run_gpu_chain*.sh`：画像生成の試作を順番に流すスクリプト
- 消してよいもの（テスト環境）
  - 検出器用とMagiV2用のPython仮想環境（下の「検出器」「MagiV2」で作るもの）
  - LLMを呼ぶための空フォルダ（下の「LLM」）
  - ComfyUIの `output/` と `input/` にできた `v3poc_` で始まるファイル（成果物は `v3poc/` に写してある）

## 試作を動かすPython
- このPCのPython 3.10.9 をそのまま使う。使うのは Pillow 10.2 と numpy 1.26（入っていたもの）。
- 画像生成の試作：`cd v3poc/pNN_名前` → `python run.py`。順番に全部流すなら Git Bash で次の4つを順に（どれも前の試作の出力ファイルができるまで待ってから始まる）。
  - `sh v3poc/run_gpu_chain.sh`：p03・p05・p08・p09・p07
  - `sh v3poc/run_gpu_chain2.sh`：p04・p10
  - `sh v3poc/run_gpu_chain3.sh`：p08の骨格と範囲の指定（`p08_rough/run_b.py`、出力は `out_b/`）
  - `sh v3poc/run_gpu_chain4.sh`：MagiV2（下の「MagiV2」）
- 一覧画像を作るだけのスクリプト：`p04_size`・`p09_identity`・`p10_page`・`p12_layout` の `make_sheet.py`。
- 余白とコマの形（p14）・絵柄と狙い（p15）
  - `cd v3poc/p14_margin` → `python run.py`（72枚＋元の絵9枚）→ `python analyze.py <venv_detのpython>`（人数・人物の高さ・枠との重なりと一覧画像 `out/sheet_<形>.png`）
  - `cd v3poc/p15_shots` → `python run.py`（4絵柄×7狙い×3 seed＝84枚。人物だけの狙いは背景を抜いた絵も出す）→ `python analyze.py <venv_detのpython>`（一覧画像 `out/sheet_<狙い>.png`）
  - `cd v3poc/p16_general` → `python run.py`（P15の狙いの言葉のまま、人物3種×場所3種に入れ替え。108枚）→ `python analyze.py <venv_detのpython>`
  - `cd v3poc/p17_identity2` → `python run.py`（参照画像で顔が揃うかのやり直し。キャラ2人×書き方3段×参照3通り×場面3×seed 3＝162枚＋参照画像2枚）→ `<venv_detのpython> analyze.py`（同一キャラ判定 CCIP と一覧画像）
  - `cd v3poc/p18_bg_consistency` → `python run.py`（箱で組んだ3Dの場所を3つの向きから描き、奥行き・線画を制御に渡す。66枚。3Dの描画は `scene3d.py`、numpy だけで動く）→ `python analyze.py`（線の重なりと一覧画像）
  - `cd v3poc/p19_expression` → `python run.py`（表情。キャラ2人×感情4種×3段＋無表情、参照の有無。108枚。P17 の参照画像を使う）→ `<venv_detのpython> analyze.py`（顔を検出して切り出した一覧と同一キャラ判定）→ `python judge.py <空フォルダ> sonnet`（LLMに2枚ずつ表情の強さを比べさせる。名前を伏せた写しを `out/blind/` に作って見せる）
  - いくつ同時に流しても、ComfyUIが1件ずつ処理するので壊れない（1枚あたりの時間は延びる）
  - 作り方の一覧：`python v3poc/recipes/build.py` → `v3poc/recipes/index.html`。元は p14・p15 の `out/gen.json` と、目で見た判定の `v3poc/recipes/labels.json`

## 検出器（dghs-imgutils）
- ほかと混ぜないため、仮想環境を別に作る。場所は任意（今回はClaude Codeの作業用フォルダ）。
  ```
  python -m venv venv_det
  venv_det/Scripts/python -m pip install --upgrade pip
  venv_det/Scripts/python -m pip install dghs-imgutils pillow numpy
  ```
- 入った版：dghs-imgutils 0.19.0。モデルは初回にHugging Faceから自動で落ちる（ユーザーのキャッシュに入る）。
- GPUでは動かない：onnxruntime のCUDA版が `cublasLt64_12.dll` を見つけられず、CPUで動く（エラーの文言が毎回出るが結果は出る）。96枚の人物・顔・頭の検出はCPUで数分。
- 使い方：`venv_det/Scripts/python v3poc/common/detect.py <画像フォルダ> <出力JSON>`。各試作の `analyze.py` は、この仮想環境のpython.exeの場所を1つ目の引数で受け取る。

## LLM（Claude Code のCLI）
- Claude Code 2.1.285 の `claude -p --model sonnet`（または `opus`）で呼ぶ。出力は `--output-format json` で受け取り、費用も記録する。
- プロジェクトの `CLAUDE.md` を読ませないため、空のフォルダを作ってそこで呼ぶ（試作の2つ目の引数でそのフォルダを渡す）。ユーザー全体の `~/.claude/CLAUDE.md` は読まれる。これが結果に効くかは未検証。
- 画像を見せる試作（`p11_vlm_order`）は `--allowedTools Read` で画像ファイルを読ませる。
- 動かし方（引数は空フォルダ、モデル）
  - コマの読む順：`python v3poc/p11_vlm_order/run.py <空フォルダ> sonnet`
  - 向き・角度・距離：`python v3poc/p11_vlm_order/judge_angle.py <空フォルダ> sonnet`（3つ目に `mixed` を付けると指示を混ぜて見せる）
  - コマ割り：`python v3poc/p12_layout/run.py 8 <空フォルダ>`（1つ目は台本ごとの回数） → `python v3poc/p12_layout/recheck.py`（小さすぎるコマと空いた場所の検査を足す）→ `python v3poc/p12_layout/make_sheet.py`

## 一覧のHTML（メモを付ける）
- 作り方：`python v3poc/checklist/build.py`。`llm_doc/V3検証の一覧.md` の表と、`v3poc/checklist/results.json`（試作の結果）から `v3poc/checklist/checklist.html` を作る。一覧の文書を直したら作り直す。
- 使い方：`checklist.html` をブラウザで開く（`file://` で動く）。各行にメモを書くと、そのブラウザに自動で保存される。
- 書き出し：「書き出し」ボタンで、メモのある行だけを `V3検証メモ_日付-時刻.json` としてダウンロードフォルダに保存する。Claude Code に「書き出した」と伝えれば、そのファイルを読んで確認する。
- 読み込み：書き出したJSONを「読み込み」で戻せる（別のPC・別のブラウザへの移し替え）。
