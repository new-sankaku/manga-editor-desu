# レビューチェックリスト

ユーザーから修正ポイントの確認を求められた際に見落とされた項目を蓄積する。
同じ問題が繰り返される場合は回数をインクリメントして優先度の目安とする。

**上限100項目。超過時は回数0の古い項目から削除する。**
