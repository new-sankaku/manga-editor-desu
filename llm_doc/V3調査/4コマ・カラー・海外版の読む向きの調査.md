## 0. 結論の一覧

- **7-2 4コマ**
  - 日本の新聞連載型は「縦4コマ」。寸法の例は横10×縦32cm（高知）、横8×縦22cm（岩手）。比率はどちらも約1：3.2と約1：2.75で、1コマの大きさは自由とされる。
  - 題は上部の枠の外に書く（高知・岩手とも）。
  - 話の型は起承転結が基本、4コマ目にオチ。ただし2段オチ・出オチ・ストーリー4コマなど外れる型が多い。
  - 4コマ誌の公式な寸法・文字量の目安は見つからなかった。
- **7-3 カラー**
  - 描画ソフト公式の資料で確認できたのは、印刷用の解像度の選択肢（カラーは350か600dpi、モノクロは600か1200dpi）、作業はRGBでCMYKはプレビュー、の2点。
  - 塗りの段取り（下塗り→影→光→仕上げ）と色の決め方は、クリップスタジオ公式の講座1本で確認。複数の出典での裏付けは取れていない。
  - 縦読みは幅800px（WEBTOON）で、紙の解像度とは別の基準。
- **7-5 海外版**
  - 英語圏では、2002年のTOKYOPOPを境に右から読むままへ移った。2018年の記事で「今も反転しているのはごく一部」。
  - フランス語・ドイツ語・スペイン語・ベトナム語でも、右から読むままが主流という記述は見つかった（根拠の強さは各章に書く）。
  - 韓国語・中国語は、右から読むままか反転かを確かめられる出典が見つからなかった。
  - 「今の海外版の多くが右から読むまま」は、英語・フランス語で言える。数えた統計は見つからなかった。

## 1. 7-2 4コマ漫画

### 1.1 結論
- 日本の4コマの基本は縦に4つ並べる形。「現代の日本ではコマの配列は縦が一般的」（原文で確認：日本語版Wikipedia）。
- 募集要項で確認できた寸法は2種類。どちらも縦長1列で、1コマの大きさは自由。
  - 横10×縦32cm、用紙はB4判（原文で確認：文化プラザ漫画館2018、第14回）。
  - 横8×縦22cm、用紙はA4（原文で確認：いわてマンガ大賞2017のSF4コマ部門）。
- 題は上部の枠の外に書く（上の2件とも原文で確認）。
- 話の型は起承転結が基本で4コマ目にオチ。外れる型も多い。

### 1.2 コマ割りの決まり
- 配列:
  - 縦が一般的。歴史的には必ずしも縦ではなく、日本以外では横並びや「田」の字の2列も見られる（原文で確認：日本語版Wikipedia）。
  - 1・4コマ目が通常で、2・3コマ目が縦長2コマ分の高さで幅が半分、横並びの形もある（同上）。
  - 欧米やタイでは3コマが多く、韓国や中国では4コマが定着している（同上。Wikipediaの記述で、出典の先は未確認）。
- コマ数: 5コマ・3コマ・8コマになる作品もある（同上）。
- 寸法の例（いずれも募集ごとの指定で、業界の標準ではない）:
  - 横10×縦32cm、B4判の市販ケント紙・画用紙・まんが用原稿用紙、枠からのはみ出し不可、題は上部枠外、CGは不可（高知の4コマまんが大賞を含む。原文で確認：文化プラザ漫画館2018のページ。CG不可は検索の要約）。
  - 横8×縦22cm、A4の白い用紙、1ページに1篇（原文で確認：いわてマンガ大賞2017）。
  - 横100×縦297mm、郵送時は折らずに封筒へ（検索の要約：4コマまんが祭り2014）。
  - コミックゼノン漫画大賞2024：B4原稿用紙にタテ270×ヨコ180mmの基本枠、周囲に20mm以上の余白、4コマは10本以上（原文で確認）。ただしこの枠の指定は作品全般のもので、4コマ専用とは書かれていない。
  - ツイ4新人賞（星海社）：データ投稿、4コマ10本、PNGのみ（検索の要約）。
- コマの比率: 1コマの大きさが自由とされているため、コマごとの比率の決まりは見つからなかった。コマ間の枠の幅の指定も見つからなかった。
- 1ページに何本置くか: 上の例は1ページ1篇（岩手）が確認できた。市販の4コマ誌での本数は未調査。
- 市販の4コマ用原稿用紙: 「原稿サイズB5・用紙サイズA4」の商品がある（検索の要約。商品ページは未確認）。

### 1.3 話の型
- 基本:
  - 「並べた4つのコマを起承転結の配置とし、4コマ目にはオチを配置するのが基本」（原文で確認：日本語版Wikipedia）。
- 外れる型（原文で確認：日本語版Wikipedia）:
  - 3コマ目にもオチを置く「2段オチ」。サブタイトルの内容が3コマ目か4コマ目で示される作品もある。
  - 萌え4コマでは4コマ目のオチが淡白になる傾向がある。
  - 「4コマ=起承転結」の前提が崩れた結果、不条理ネタや雑学を扱う作品が増えた。
- 続き物（ストーリー4コマ）:
  - 各4コマごとにオチを付けながら、物語は完結させず次の4コマに続け、おおむね10〜15本前後で一つの物語をなす（原文で確認：日本語版Wikipedia）。
- 1コマ目の役目・3コマ目の転じ方:
  - 出版社・専門学校・描画ソフト公式の解説は見つからなかった。
  - 作家の発言は原文で確認できた（ファミ通「町内会サミット」）。ただし個人の制作談で、型の決まりではない。
    - とがわ氏は3コマ目を最初に描き、「4コマ目のおもしろさが3コマ目を超えなくてもいい。もう1個オチがあればいい」。
    - 別の作家は題名から連想して1コマ目を描き、もう1人は1コマ目から順に描いて描きながら考えた。
  - 学術ポスターに「標準は起承転結で原則4コマ目にオチ、1コマ目で落とす出オチもある」とある（検索の要約）。
- 1コマの文字量の目安: 見つからなかった。

## 2. 7-3 カラー漫画の描き方

### 2.1 結論
- 紙の印刷用では、描画ソフトの新規作成でカラーは350dpiか600dpi、モノクロは600dpiか1200dpiを選ぶ（原文で確認：クリップスタジオ公式ヘルプ）。
- 色の扱い:
  - クリップスタジオはRGBでしか作業できず、CMYKはプレビューで確かめる（原文で確認：クリップスタジオ公式Tips）。
  - 紙は光を出さないので、RGBより色が暗く見える（同上）。
- 塗りの段取りと色の決め方は、クリップスタジオ公式講座の1本（淡い色づかいのイラスト）で確認。漫画のカラーページ専用の講座ではない。
- 縦読みは別の基準で、幅は画面基準（WEBTOONは幅800px）。

### 2.2 白黒との違い
- 色の決め方（原文で確認：クリップスタジオ公式「イラストの淡い色づかいの塗り方講座」。1本の作例であり一般則ではない）:
  - 使う色を少なめにし、ベース・メイン・サブ・アクセントの4種に分ける。
  - 白の面積を広くすると淡い雰囲気になる。
  - アクセントは少量にする。
- キャラごとの色・場面ごとの色の決め方: 見つからなかった。
  - 縦読みの記事に「繰り返し出るキャラの色はカラーセットに保存」とある（原文で確認：クリップスタジオ公式の縦読み解説）。
  - 同記事に「回想はベタの黒や枠線の代わりにセピアで示す」「トーンと黒ベタの代わりに色で雰囲気や時間を表す」とある（同上）。これはトーンの代わりに関する出典として使える。
- 塗りの段取り（原文で確認：同上の講座）:
  - 下塗り：パーツごとにベースの色を塗る。
  - 影：ベース色の明度を少し下げ、彩度を少し上げ、色相を寒色側へ寄せて作る。影の面積は最小限にする。
  - 光：光が最も当たる部分にエアブラシで薄い色を置き、白のハイライトを入れる。影の境界に薄いオレンジのフチを足す。
  - 仕上げ：描き足し、効果レイヤーで色を整え、トーンカーブで中間色を少し濃くする。
  - 順序そのものは、技術評論社の書籍資料にも「下描き→線画→下塗り→影→光→仕上げ」とある（検索の要約）。
- 線の色（原文で確認：同上の講座）:
  - 線画レイヤーを乗算にし、光の強い部分や色の薄い部分で白のエアブラシで線を薄くする（色トレス）。線が消えすぎないよう調整する。

### 2.3 印刷用（CMYK）と画面用（RGB）、解像度
- 解像度の選択肢（原文で確認：クリップスタジオ公式ヘルプ「新規キャンバスの作成」）:
  - 基本表現色がモノクロ：600か1200dpi。
  - カラーまたはグレー：350か600dpi。
  - 塗り足し幅は5mmか3mm（コミック用）。イラスト用には塗り足し幅の設定がない。
- 色（原文で確認：クリップスタジオ公式Tips、RGBとCMYK）:
  - 画面だけで見るものはRGB、印刷するものはCMYK。
  - 作業中のCMYKプレビューは、印刷会社の指定のプロファイルに合わせる。
- 印刷所の資料（クリップスタジオ公式の解説。原文で確認）:
  - 「フルカラー原稿は解像度350dpi、モノクロ原稿は600dpi以上あるのが望ましい」。
  - RGBで入稿できる印刷所もあるが、一部で、料金が高い。
  - プレビューのプロファイルは Japan Color 2011 Coated にするとある。
  - 印刷所の入稿規定は所ごとに違うため、入稿前に確認する。
- 総インキ量300%以内などの注意（検索の要約。個人・制作会社のサイトで、印刷所の公式基準ではない）。
- 白黒は600dpi以上でアンチエイリアスなし、カラーは350dpiでアンチエイリアスあり、という作例（検索の要約：クリップスタジオ公式Tips。同記事を開いたところ、この文言と350dpi・カラーのプリセットは見つからなかった。検索の要約として扱う）。

### 2.4 縦読みのフルカラーと紙のカラーページの違い
- 縦読み:
  - 幅は一般的なスマートフォンの画面に合わせる。高さは掲載先の制限に従う（原文で確認：クリップスタジオ公式の縦読み解説）。
  - 例：WEBTOONは幅800px・高さ1280px。Tapas は幅940px・1枚4000px（同上）。
  - 解像度は WEBTOON なら72dpi以上でよいとある（同上）。
  - 掲載先の公式の取扱説明では、1画像は幅800px未満・長さ1280px未満、JPG/PNG、1枚2MB以内（検索の要約：WEBTOONクリエイター向けハンドブック。古い版かもしれず更新日は不明）。
  - コマの周りの背景は白に限らず、黒やテーマの色もある（原文で確認：同上）。
  - 紙の漫画との違いは、コマが縦に並び間の余白が大きいこと（同上）。
- 紙のカラーページ:
  - 350dpi・CMYK・塗り足し3〜5mm（2.3 の出典）。巻頭カラー専用の規定は見つからなかった。

## 3. 7-5 海外版の読む向き

### 3.1 結論
- **英語版**：2002年以前は「英語で出た漫画の大半が反転」（原文で確認：ANN 2015）。2002年のTOKYOPOPが右から読むままへ移り、数か月後にVIZが続いた（同上）。2018年のANNは「今も反転しているものはごく少ない」と書く（原文で確認）。
- **フランス語版**：2011年のFnacの記事に「多くのフランスの出版社が元の読む向きを選んだ」（原文で確認）。反転の例と現在の例外は検索の要約のみ。
- **ドイツ語版**：Carlsen が1997年に『ドラゴンボール』を右から読むままで出した（検索の要約）。
- **スペイン語版**：Norma が公式サイトで「日本の読む向きを守ってきた」と述べている（検索の要約）。
- **ベトナム語版**：2013年の記事で、出版社Kim Dongが翻訳は全て右から読む配置と述べた（原文で確認）。
- **韓国語・中国語版**：確かめられる出典が見つからなかった。
- **反転して出している例**：今もある（3.3）が、いずれも少数。市場として反転が主流の言語は見つからなかった。

### 3.2 言語ごとの根拠
- **英語**
  - ANN（2015-10-21、Answerman、原文で確認）:
    - 2002年より前は「英語で出た漫画の大半が"flopped"」で、読みやすいよう左から右へ反転していた。
    - 作家は反転を嫌った。野球や剣の動きなど向きが大事な場面が壊れる。
    - 2002年にTOKYOPOPが「100% Authentic Manga」で反転なしに作り直し、VIZが数か月以内に続いた。
    - 例外は『Gon』など少数の美術寄りの本。
  - Publishers Weekly（2002-03-18、原文で確認）:
    - TOKYOPOPの新シリーズは書籍の背が右側で、各ページは右から左へ読む。
    - 「Manga done the right-to-left way」の売り場表示。以前から他社も出していたが、全面的に踏み込んだのはTOKYOPOPが最初。
    - 理由として広報担当は、反転しない方が安く作れるので刊行の頻度を上げられる、と述べた。
  - ANN（2018-09-14、Answerman、原文で確認）:
    - 今も反転しているのは『Chi's Sweet Home』（Vertical、カラー）、『子連れ狼』（Dark Horse、白黒）、VIZのカラー版『ドラゴンボール』。「very few titles」。
    - 反転をやめた理由は、読者が元の形を受け入れたこと、費用と時間がかかること、顔が左右ずれて見えること。
  - 初期の反転がやめられた経緯:
    - 鳥山明が反転を認めず元の形を求めた、というのが多くの記事の説明。ただし開いたページの範囲では一次の出典（本人の発言や出版社の文書）は確認できていない。
    - TOKYOPOPのStu Levyは2005年のインタビューで、最初は書店が日本式を試したがらず反転が必要だった、と語った（検索の要約。国際交流基金の資料経由）。
  - VIZの公式の説明文: 見つからなかった。VIZのマーケティング担当者が「『エヴァンゲリオン』の左から右の版が右から左の版より3対1で売れた」と述べた、という話は、ファンのwikiの記述で一次の出典を確認できなかった（検索の要約）。
  - Yen Press・Seven Seas・講談社USAの公式の説明: 見つからなかった。
- **フランス語**
  - Fnac「Comment lire un manga」（2011-09-30、原文で確認）: 「多くのフランスの出版社が元の読む向きを選んだ」。以前は欧州式に組み直していたことが示唆される。
  - Glénat は『AKIRA』1990年、『ドラゴンボール』1993年から元の向きが現れた（検索の要約：DailyGeekShow）。Wikipedia（英語、出典なしの節）は、Glénat が西洋の向きに合わせて各コマを反転したと書き、J'ai Lu は元の向きを保ったとある（原文で確認したが、その節は出典なしの表示）。
  - Kana は『NARUTO』66巻の紹介で「元の読む向き（右から左）で刊行」と明記（検索の要約）。
  - 例外：Glénat Kids の『チーズスイートホーム』はカラーで西洋式の向き、Casterman に西洋式に直した漫画の叢書がある（検索の要約）。
- **ドイツ語**: Carlsen の『ドラゴンボール』は1997年、日本の読む向きで刊行。Carlsen 自身が1997年を節目としている（検索の要約。Wikipedia は1996年末と書くが、これは確認できず1997年の方が検索結果では多い）。
- **スペイン語**: Norma は公式サイトで「日本の読む向きを守って普及に努めた」（検索の要約）。Planeta Cómic の2002〜2003年の『ブッダ』は反転（検索の要約：Tebeosfera）。Planeta の公式ブログ（原文で確認）は右から左と説明するが、反転の有無には触れていない。
- **ベトナム語**（Tuoi Tre、2013-05-24、原文で確認）: 著作権の条約に入る前は、ページを取り込んで左から右へ反転して出した。Kim Dong の担当者は、翻訳の日本漫画は全て右から左の配置と述べた。権利者は元の配置を保つよう求める。
- **韓国語**: 出典が見つからなかった（検索は2回、該当なし）。
- **中国語**: 台湾・大陸とも、版ごとの向きを書いた出典が見つからなかった。

### 3.3 反転して出している例（市場が今もあるか）
- 英語：3.2 の ANN 2018 の3例（Chi's Sweet Home、子連れ狼、VIZのカラー版ドラゴンボール）。2018年時点の情報で、現在の状況は未調査。
- フランス語：Glénat Kids の『チーズスイートホーム』、Casterman の叢書（検索の要約）。
- 子供向け・カラー・古い作品に反転が残る傾向は見えるが、数えた統計は見つからなかった。
- VIZ Originals など、英語で新しく作る作品は左から右（Publishers Weekly の要約。検索の要約）。これは翻訳ではなく書き下ろしで、反転ではない。

### 3.4 「今の海外版の多くが右から読むまま」と言えるか
- **英語**：言える。根拠はANN 2015・2018と Publishers Weekly 2002（原文で確認）。時期は2002年以降。
- **フランス語**：言える。根拠はFnac 2011（原文で確認）。
- **ドイツ語・スペイン語・ベトナム語**：言える方向だが、ドイツ語・スペイン語は検索の要約のみ。ベトナム語は1社の発言（原文で確認）。
- **韓国語・中国語**：言えない（出典が無い）。
- **全体の統計**：見つからなかった。
- 注意：現在（2026年）の個別の出版社（Yen Press・Seven Seas・講談社USA・Glénat・Kana など）の方針の公式説明は見つからなかった。「多く」は、英語・フランス語の記事に基づく見方で、数えた結果ではない。

## 4. 見つからなかったもの
- 4コマ誌（まんがタイムきらら等）の投稿規定。
