## 2. 評価の手段

「アニメ」欄: 済＝アニメ絵か漫画で人との一致や精度を測っている／一部＝アニメを含むが画風別の数字なし／未＝写真・一般画像のみか記載なし。

## 4. 漫画ハーネスの評価役に当てはめるなら（すべて推測。アニメ・漫画で検証された組み合わせではない）

1. 指示との一致
   - 人数: 漫画の人数判定は GPT-4o で 0.963 と高いが、一般画像では数の判定 67.4%。Magi のキャラ検出（漫画で AP 0.85〜0.90）で数え、VLM は補助にする案。カラーのアニメ絵での精度は未確認。
   - 距離（ショットの大きさ）: VLM は隣の区分を約36%取り違える。検出したキャラの枠や顔の大きさをコマの大きさとの比で測る機械検査の方が向く見込み（研究での検証は見つからず）。
   - 向き・視線: VLM は視線を頭の向きで推し量り、対象4個で30%。視線を正しく判定する手段はアニメ絵では見つからなかった。**手段なし**。
   - 表情の強さ: 表情の種類は漫画で 0.708。強さを測った研究は見つからなかった。**手段なし**。一対比較で「どちらが強いか」を聞く形なら、絶対点より人と合いやすい可能性（MLLM-as-a-Judge の傾向からの推測）。
2. 見切れ: 研究としての評価手段は見つからず。キャラ検出の枠がコマの端に接しているかを見る機械検査が候補（推測）。
3. キャラの一貫性
   - 顔・髪型: CCIP（アニメで F1 0.941）。ただし髪の色・肌の色に鈍いと明記されているので、色は別に画素で比べる必要がある。
   - 服・アクセサリー・小物: 確立した手段なし。参照画像と並べて属性ごとに はい/いいえ で聞く形が候補だが、画像編集の研究で VLM の同一性判定は人と相関しなかった（r≈-0.067）。**手段なし（要検証）**。
   - 背景: ViStoryBench 自身が背景の一致は評価できていないと明記。**手段なし**。
4. 画風の一貫性: CSD（画風一致と利用者評価 0.6042）が候補。ただしアニメでの検証なし、作者の癖を拾う性質の指摘あり。1作品内で「同じ画風か」を見る用途なら作者の癖を拾う性質は害にならない可能性（推測）。
5. 破綻（ぼやけ・輪郭の潰れ・手）
   - 人体・手: アニメを含む人体破綻の専用検出器（Distortion-5K 型、F1 0.884）が汎用 VLM（0.246）より大幅に良い。学習済みモデルの公開状況は未確認。数百例で VLM を調整する方式（ArtifactReward 80%、ArtifactLens）も候補。
   - ぼやけ・線の潰れ: 従来の画質指標はアニメで単純な絵を高く付ける偏りがある。アニメの線画のぼやけを判定する検証済みの手段は見つからず。**手段なし（機械的な鮮鋭度検査は未検証）**。
6. 描き込み・彩度の過多: 人の好みを学んだモデルは彩度・見栄えを好む方向に偏るので、これで候補を選ぶと過多を選びやすい（推測）。彩度は画素の統計で、描き込みは画像の複雑さ評価（APISR が使用）で数値化できるが、「過多」の境目を決めた研究は無い。**閾値は手段なし**。
7. 漫画ページとしての読みやすさ・コマ割り
   - 機械で測れるもの: コマ数、指定レイアウトとのずれ、コマの重なり、紙面の被覆（MangaFlow）。吹き出しが顔を隠すか（MangaFlow は人が採点。顔検出で機械化する案は、漫画の顔が取りにくいと著者が書いているので要検証）。
   - VLM の読みやすさ採点は人より 1.25 甘いが、方式の優劣は 96% 一致 → 候補同士の比較にだけ使う。
   - 読む順番: Magi の順序付けがあるが正解率の数字なし。眼球運動研究（吹き出しを前のコマから離すと読み飛ばしが減る、読む順は主に外枠で決まる）を規則の検査に落とす案（推測）。
   - 複数コマの流れの良し悪し: VLM はほぼ偶然レベル。**手段なし**。
8. 審美眼（漫画として良いか）: **手段なし**。既存の美的予測器はアニメに偏った高得点。専門家の採点を集めて学習した美的モデル（ERNIE-Image-Aes 方式、スイス式トーナメントで採点）を自前で作る道はある。少数なら、人が点を付けた見本数枚と比べさせて点に直す方式（Compare2Score）が Anthropic 記事の「採点付きの見本で合わせる」に近い。
9. 評価役自体の精度の測り方（当てはめ）
   - 人が採点した見本セットを用意し、一致率だけでなく κ か Scott's π を出す。人同士の一致を上限として並べる。
   - 一対比較は順番を入れ替えて2回。食い違いは引き分け扱い。
   - 生成と同じ系列のモデルを審査に使わない。使うなら別系統と合議（自己びいきの対策）。同じ審査員の多数決は効きが小さい。
   - 見本を入れる場合は、見本の判定をそのまま写していないかを検査する（LLaVA で 88.2% 写しの例）。
   - 基準は先に数十枚を人が採点してから書き、採点しながら直す（EvalGen）。細かすぎるルーブリックは一致を下げた例がある。
