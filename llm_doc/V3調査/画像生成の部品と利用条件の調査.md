# 画像生成の部品と利用条件の調査（調査日 2026-09-30）

取得方法の注意:
- 利用条件は、配布元の登録情報（Hugging Face の API、Civitai の API、GitHub の LICENSE の原文、OpenModelDB）をコマンドで直接取った。
- 検索結果の要約（WebSearch）は、検索エンジン側の小型モデルがまとめたもの。原文とは照合していない。本文で「検索の要約」と書いたものがそれに当たる。
- 法的な判断ではない。商用に使う前には、各配布元の条件の原文を読む必要がある。

## 1. 結論

- **SDXL系で人物の位置と姿勢を渡す部品のうち、商用に使える（Apache-2.0）もの**
  - xinsir の骨格（controlnet-openpose-sdxl-1.0）
  - xinsir の多用途版（controlnet-union-sdxl-1.0。骨格・奥行き・線画などを1つで扱う）
  - windsingai の Illustrious 向け骨格（Illustrious-XL-openpose-test）
  - TencentARC の骨格（t2i-adapter-openpose-sdxl-1.0）
  - kohya の軽量版（controlnet-lllite。アニメ向けの骨格を含む）
- **前回の試作で位置が最もよく合った thibaud の骨格（thibaud_xl_openpose）は使えない。**
  - 配布元の条件は「OpenPose の条件に従う」。
  - OpenPose（CMU）の条件は「非営利の研究用だけ」。
- **検証に使ったほかの部品にも、商用に使えないものがある。**
  - MagiV2：非営利だけ。
  - 4x-UltraSharp：CC-BY-NC-SA-4.0。
  - NoobAI系：独自の追記で商用を禁止。
- **使っている絵のモデル（WAI-illustrious-SDXL）**
  - 元の Illustrious v0.1 の条件（Fair AI Public License 1.0-SD）では、生成した画像にこの条件は及ばない。
  - ただし、派生モデルをネット越しに使わせるときは、モデルの入手手段を示す義務がある。
  - Civitai の表示は「画像の商用可」「Civitai上での貸し出し可」。自前のサービスとして貸し出す許可は付いていない。
- **Civitai の商用可否の表示は掲載者が付けるもので、元の条件と食い違う例がある。**
  - NoobAI の骨格は、Civitai では「販売可」と表示されている。
  - 元の NoobAI の条件は商用を禁止している。
  - 利用条件は、配布元（Hugging Face など）の原文で確かめる。

## 3. 余白・コマの形について分かったこと

- **SDXL は複数の縦横比で学習している。**
  - 得意な大きさは次のとおり（検索の要約）。
    - 1:1（1024x1024）
    - 約4:3（1152x896）
    - 約16:9（1344x768）
  - それより極端な横長・縦長で作ると、人物が増える・重なることがある。
  - 原因は、学習より大きい・違う形で作ると、特徴が重なって出ること（HiDiffusion の論文）。
- **対策は2つある。**
  - 生成の初めだけ縮小して作る（Kohya の Deep Shrink。ComfyUI の標準部品 PatchModelAddDownscale）。
  - 普通の形で作ってから、コマの形に描き足す（アウトペイント）。
- **範囲ごとに指示を分ける手（地域指定）は、モデルに関係なく使える**（検索の要約）。
  - コマの一部にだけ人物を、残りに風景を頼める。
  - ComfyUI の標準の範囲つきの条件（ConditioningSetArea）もこの一種。前回の試作では位置の重なり0.67。
- **漫画の研究**
  - DiffSensei（CVPR 2025、MIT）は、コマの枠と人物の位置を渡して白黒のコマを作る。
  - コマの大きさは辺64〜2048の範囲で変えられる。
  - 手元では未検証。
