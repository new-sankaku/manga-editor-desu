# V3 の AIハーネスの実装（2026-10-08）

`v3/server/src/v3server/harness/` に置いた工程の進行役と作業の流れ、それを見て動かす画面 `v3/web/harness/` の文書。
設計は `V3ハーネス設計.md`、細部は `V3細部の決めごと.md`。ここには、作ったもの・確かめたこと・まだ作っていないものを書きます。

## 1. 作ったもの

### 1.1 流れ（Temporal）
- **StageWorkflow**（`stage_workflow.py`）が1つの工程の実行（S0〜S7 のどれか1つ）を進めます。作業を切り出し（`prepare_stage`）、
  同時に回す数の上限まで子の作業を起こし、全部が終わったら工程の検査（`stage_check`）をして、人の承認を待ちます。
  承認されると次の工程の実行を作ります（`advance_stage`。S7 の次はありません）。
- **WorkUnitWorkflow**（`unit_workflow.py`）が作業1つの流れです。段は「切り出し → 文脈 → 生成 → 検査 → 評価 → 人の判断 → 確定」。
  やり直しの線（検査や評価で外れた → 文脈へ戻る）と、却下（人の判断 → 文脈へ戻る）があります。
- 作業を切り出すのは S3（ネーム。`name_draft_steps.py`）と S4（作画。`panel_drawing_steps.py`）だけです。
  ほかの工程は作業を切り出さず、工程の検査に「人が中身を見て次へ進める」と書いて承認を待ちます。
- 判断待ち・止めた・止まった・決めるまで進めない（`WAITING_HUMAN`）の作業は、同時に回す数に数えません。
  人を待つ作業が上限を埋めて、ほかの作業が進まなくなるのを避けるためです。
  作業がこの状態に入るときと出るときに、親へ `unit_waiting` の Signal を送ります。
- 止める操作は3つです。
  - 段の切れ目で止める
  - 今すぐ止める：ComfyUI の実行を `prompt_id` 付きで止めます。再開すると同じ段からやり直します
  - 取り消す：半端な候補は却下にします
- そのほかの操作は次のとおりです。
  - 上限を変える
  - 人の判断：採用、理由をつけた却下（理由は次の回の問いに入ります）、人が直した絵から続ける（人の手の範囲を守る処理で作ります）
- 上流（コマの中身・設定資料など）が変わると「古い」の印を付けます（`upstream_watch.py`）。自動では作り直さず、人が頼んだときだけ作り直します。
  印の付いた作業がまだ動いているときは、段の切れ目で止めます。
- 送り先への依頼は、今ある順番待ち（GenerationJob）を通します（`queue_calls.py`）。`harness_key` で同じ依頼を重ねません。
  ただし、いちばん新しい依頼が取り消しになっていれば頼み直します。今すぐ止めたあとの再開がこれに当たります。

### 1.2 正本の記録と口
- 表（移行 `0013_ai_harness.py`。0012 の後）は次の7つです。
  - `harness_stage_runs`
  - `harness_units`
  - `harness_steps`
  - `harness_candidates`
  - `harness_events`
  - `harness_stale_marks`
  - `harness_watch_cursors`
- 口は `/works/{id}/harness/` の下にあります（`harness_routes.py`）。
  - 工程を始める：`POST stages`
  - 工程の操作：`POST stages/{id}/control`、`approve`、`rerun`
  - 作業の操作：`POST units/{id}/control`、`review`、`limits`
  - 古い印を外す：`POST stale/{id}/dismiss`
  - 読む口：`GET snapshot`、`units/{id}`、`review-items`（判断待ちの一覧）、`stage-runs`、`stream`（SSE）
- SSE（`live_stream.py`）は `harness_events` を順に流します。`?after=<last_event_id>` で続きから読めます。何も無いときも15秒ごとに生存の知らせを送ります。
- ComfyUI の進み具合と途中の絵は `service_call_progress` に書きます（`service_senders/comfyui_progress.py`）。

### 1.3 画面（`v3/web/harness/`）
- 開き方は `/web/harness/?work=<作品の id>` です。共通の帯（`common/nav.js`。`data-v3-nav="harness"`）からも開けます。
- 2つのタブがあります。
  - **工程の図**：S0〜S7 の段と、今の工程の作業を格子に並べます。作業ごとに状態の色と進み具合の帯を出します。
  - **作業の図**：1つの作業の段と、やり直しの線を出します。辿った線には動く印が走ります。生成の段には進み具合の帯と途中の絵を重ねます。
- 図の下には時間の帯があります。右のパネルには次のものを出します。
  - 作業の操作
  - 判断待ちの採用と却下
  - 上限の変更
  - 候補の一覧
  - 工程の検査
- 一番下はページとコマの表です。
- 図は Cytoscape 3.34.3 と cytoscape-dagre を手元に置いて読みます。React は使いません。
- 書き込みの要求（GET 以外）には、どれにも `X-V3-Request: 1` を付けます（`harness.js` の `call()`）。
- **色**：`common/theme.css` の変数だけを使い、色の値は書きません。
  - 状態の色の呼び名（`--run`・`--review`・`--stale` など）は `harness.css` の `:root` の1か所で、theme.css の変数と `color-mix()` から作ります。
  - 図（`harness_graph.js`）は、この呼び名を `getComputedStyle` で読みます。Cytoscape は CSS の変数も `color-mix()` も読めないので、ブラウザに解かせた色を1画素の canvas で rgb にしています。
  - theme.css にまだ無い状態の色は、近い変数から作っています。
    - 古い：`--ink-2`
    - 動いている作業の下地：`--ok` を `--surface` に混ぜたもの
    - やり直しの線：`--need-ink`
  - 色の組を替えるときは theme.css だけを直します。状態の色の呼び名を theme.css に足したら、`harness.css` の `:root` を差し替えます。
- **SSE**：`EventSource` は `X-V3-User` を付けられないので、fetch の stream で読みます（`harness_sse.js`）。
  - 35秒何も来なければ切れたとみなし、「切断中」を出します。
  - つなぎ直すときは snapshot を取り直してから続きを読みます。

## 3. 確かめて分かったこと
- **今すぐ止めても、ComfyUI に止める指示が届くまで最大5秒かかります。**
  - 送信の活動（`service_call_activity.py`）は5秒ごとに生存を知らせ、取り消しはその知らせへの返事で初めて届きます（`HEARTBEAT_SECONDS = 5`）。
  - 依頼（GenerationJob）は TRY_CANCEL なので、状態はすぐ「取り消した」になります。ComfyUI の `/interrupt` はその後に届きます。
  - 作業者の間引きは1秒にしました（`queue_worker_main.py`）。`service_call_activity.py` は今回触っていません。
- **進み具合の書き込みが NOT NULL で落ちていました。** PostgreSQL は、upsert の衝突を見る前に、挿入する行の NOT NULL を確かめます。
  `state` の無い進み具合の upsert は IntegrityError になっていたので、挿入する行にだけ `state: pending` を入れました。
  `test_進み具合はstateの無い書き込みでも落ちない` で確かめています。
- **画面に届くまでの時間**：出来事の `created_at` から画面に反映するまでを、偽物の見本で1回測りました。
  - 全部の出来事：中央値 193ms、95% 445ms、最大 4954ms（切断からつなぎ直す間の進み具合）
  - 作業の出来事：中央値 226ms、95% 408ms
  - 段の出来事：中央値 238ms、95% 433ms
  - 却下を押してから印が動き出すまで：約1.5〜1.7秒
  - つなぎ直し：約1.25秒
  - 本物の送り先や、多い作業で測ったことはありません（**未検証**）。
